# SolarAngleCalculation

Hosted live through Streamlit Community Cloud at https://solaranglecalculation-gerlock.streamlit.app/

This is a python Streamlit app that calculates solar position, then outputs building shading requirements based on the user-inputted location, dates, times, and building orientation. The app helps architecture students and professors determine appropriate designs and angles for windows when designing their buildings.

The map is made with the Folium library, allowing the user to input their approximate location without having to type in latitude and longitude manually.

All of the credit for the calculations belongs to Johnathon Gerlock. I just converted it to Python, then Streamlit.

Libraries:
- Streamlit
- Folium
- Numpy
- Pandas
